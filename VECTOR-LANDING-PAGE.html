Skalar vs Vektor (5.1)

Ketahui perbezaan asas yang memisahkan skalar dari vektor

🔢
Skalar (Scalar)
Kuantiti yang hanya mempunyai magnitud (saiz) sahaja. Tiada arah.
Contoh: 25°C 50 km/j
➡️
Vektor (Vector)
Kuantiti yang mempunyai magnitud DAN arah. Kedua-dua penting.
Contoh: 50 km/j Utara 500 N ke bawah
📊
Magnitud
Skalar: Ya saja | Vektor: Ya + Arah
🧭
Arah
Skalar: Tidak | Vektor: Penting
➕
Penambahan
Skalar: 3+2=5 | Vektor: Mesti guna gambar
🔤
Notasi
Skalar: 5 m/s | Vektor: 5i+3j m/s
🎯
Jenis-jenis Vektor
Vektor Null: Tiada panjang, tiada arah (0)
Vektor Unit: Panjang = 1 unit (i, j)
Vektor Selari: Arah sama, panjang mungkin berbeza
Vektor Sama: Arah sama DAN panjang sama
Vektor Negatif: Arah bertentangan
Mudah - Asas

Vektor dalam Satah Cartes (5.2)

Pelajari cara mengungkapkan vektor dalam bentuk komponen i, j

📐
Bentuk Komponen (i, j)
Vektor = xi + yj
i: Unit vektor arah x (Timur)
j: Unit vektor arah y (Utara)
Contoh: 3i + 4j
📊
Bentuk Kolom
Vektor boleh ditulis dalam bentuk kolom:
[3]
[4]
Bererti 3 unit Timur, 4 unit Utara
Juga dipanggil: Column vector
📏
Magnitud Vektor
Formula: |v| = √(x² + y²)
Contoh: Jika v = 3i + 4j,
|v| = √(9 + 16) = √25 = 5
Panjang vektor

📍 Koordinat ↔️ Bentuk Komponen:

  1. Titik (2, 3): Vektor = 2i + 3j
  2. Titik (5, -1): Vektor = 5i - 1j
  3. Titik (-3, 4): Vektor = -3i + 4j
  4. Ingat: Negatif bermakna arah sebaliknya
🔵
Komponen i
Selalu BIRU (Timur/Barat)
🔴
Komponen j
Selalu MERAH (Utara/Selatan)
📐
Unit Vektor
i = (1, 0), j = (0, 1)
➡️
Arah
θ = arctan(y/x)

Penambahan & Pengurangan Vektor (5.3)

Dua kaedah untuk menambah vektor: Hukum Segitiga dan Hukum Segiempat Selari

△
Hukum Segitiga
1. Lukis vektor A dari O
2. Dari hujung A, lukis vektor B
3. Vektor paduan: O ke hujung B
Hasil: A + B
Sederhana
▭
Hukum Segiempat Selari
1. Lukis A dan B dari O
2. Lengkapkan segiempat selari
3. Pepenjuru = vektor paduan
Hasil: Sama dengan hukum segitiga
Sederhana
➕
Penambahan Algebra
Formula:
(a+c)i + (b+d)j

Contoh:
(3i+4j) + (2i-1j) = 5i+3j
Mudah
➖
Pengurangan
Formula:
(a-c)i + (b-d)j

Ingat: A - B = A + (-B)
Sederhana

📝 Langkah-langkah Menambah Vektor:

  1. Langkah 1: Tulis vektor dalam bentuk xi + yj
  2. Langkah 2: Tambah komponen i dengan komponen i
  3. Langkah 3: Tambah komponen j dengan komponen j
  4. Langkah 4: Tulis jawapan sebagai vektor baru
  5. Langkah 5: Lukis gambar untuk sahkan jawapan
🔑
Sifat-sifat Penambahan Vektor
Komutatif: A + B = B + A
Asosiatif: (A + B) + C = A + (B + C)
Identiti: A + 0 = A
Songsang: A + (-A) = 0
Mencabar

Sumber dan Petua 💡

Rujukan cepat, kesilapan biasa, dan formula penting

⚠️
Kesilapan Biasa
❌ Salah: "3i + 4j = 7" (mencampurkan komponen)
✓ Betul: Komponen i dan j harus ditambah secara berasingan

❌ Salah: "Untuk tambah vektor, cukup tambah magnitud"
✓ Betul: Mesti guna hukum segitiga atau segiempat selari

❌ Salah: "-3i bermakna tiada komponen i"
✓ Betul: Negatif bermakna arah sebaliknya (3 unit ke Barat)
📐
Formula Penting
Bentuk Komponen: v = xi + yj
Magnitud: |v| = √(x² + y²)
Unit Vektor: u = v / |v|
Penambahan: (a+c)i + (b+d)j
Pengurangan: (a-c)i + (b-d)j
Pendaraban Skalar: kv = (kx)i + (ky)j
Vektor Selari: A || B jika A = kB
Vektor Sama: A = B jika i dan j komponen sama
📚
Rujukan Cepat
Warna Kod:
🔵 Biru = Komponen i (arah x)
🔴 Merah = Komponen j (arah y)
🟢 Hijau = Vektor paduan

Nota Ringkas:
• Skalar: Magnitud sahaja (25°C, 50 km/j)
• Vektor: Magnitud + Arah (50 km/j Utara)
• Komponen: Bahagi kepada x dan y
• Penambahan: Tambah i dengan i, j dengan j
